# Infra Monitoring Project

Учебный DevOps-проект для мониторинга доступности API,
анализа логов и контейнеризированного развёртывания.

## Технологии

- Bash
- Git и GitHub
- Wireshark
- Docker Compose
- Nginx
- GitHub Actions
- SSH/SCP

## Структура проекта

- check_api.sh — проверка доступности API
- analyze_logs.sh — анализ HTTP-логов
- docker-compose.yml — запуск API и Nginx
- nginx.conf — конфигурация обратного прокси
- .github/workflows/ci.yml — CI/CD

## Запуск

Инструкции по запуску и развёртыванию будут добавлены
по мере реализации проекта.
